EMAN ALANSARI PORTFOLIO
=======================

A standalone, single-page portfolio for Eman Alansari (Software Developer · Information Systems), based in Isa Town, Bahrain.

FILES
-----
index.html          Page content and semantic structure.
css/style.css       All visual styling, responsive layout, avatar, and animations.
js/main.js          Scroll reveal and lightweight particle background.
assets/cv.pdf       Copy of Eman Alansari's uploaded CV.
assets/*.svg        Offline-safe project placeholder artwork.
assets/README-assets.txt  Note explaining image placeholders and replacement.

OPEN LOCALLY
------------
Double-click index.html, or serve this folder for a local preview:
  python3 -m http.server 8000
Then open http://localhost:8000 in a browser.

EDIT QUICKLY
------------
- Change text, links, and project details in index.html.
- Change colors and spacing at the top of css/style.css under :root.
- Replace the SVG placeholders in assets/ and update their image paths in index.html.
- Change animations in css/style.css or particle settings in js/main.js.

NOTES
-----
The Google Fonts link is optional; the page falls back to a local sans-serif/monospace stack if offline. The CV download link points to assets/cv.pdf. Contact links use the email, phone, LinkedIn, and GitHub supplied by Eman / CV.
